# 原 C2 Skill 阅读说明

这个目录保留实验时使用的两份英文原件，文件内容与记录的 SHA256 一致：

- [SKILL.md](SKILL.md)：根据任务结果，填写正确的用餐方案。
- [references/mcp-tools.md](references/mcp-tools.md)：取餐方式、金额单位和模拟环境中的错误说明。

原版主要指导模型完成五件事：

1. 判断方案可行、预算不足、其他条件无解、需要澄清，还是服务不可用。
2. 按结果填写商品、金额和原因；只有已证明预算不足时，才填写最低所需金额。
3. 使用一次完整购物车的实际报价，并核对优惠券适用情况。
4. 分清硬性要求、偏好和替代许可，结合工具结果解释发生的情况。
5. 引用本次调用返回的 `traceId`，检查字段齐全后写出 `plan.json`。

第二批 C2 重点调整了“偏好商品不可用”的判断：既要有用户独立表达的偏好，也要有商品不可用的依据。硬性要求是否能满足、是否允许替代，分别判断。

原版采用固定模拟场景、预设输出格式和工具说明。连接真实麦当劳服务时，请使用 [提交版 Skill](../../skills/mcd-meal-plan-output/)，实验结果与版本信息见 [研究记录](../README.md)。
