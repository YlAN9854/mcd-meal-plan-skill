# 从研究版到真实 MCP 的适配

原件：`research/c2/`；可安装入口：`skills/mcd-meal-plan-output/`。原件保持逐字节一致，提交版没有使用留出题细节或最终失败案例进行调整。

| 研究环境条件 | 真实入口的处理 |
| --- | --- |
| 固定场景端点 `http://mcp:8000/mcp` | 用户客户端连接官方 `https://mcp.mcd.cn`，环境变量提供Token |
| 固定 `plan.schema.json` 和工作区路径 | 默认返回人可读方案；需要JSON时使用本项目可选输出格式 |
| 场景已给定完整菜单属性 | 仅使用实时返回信息，库存、营养等缺失属性保持未知 |
| 小型封闭组合空间可证明最低价/无解 | 真实搜索不充分时标记incomplete，不声称全局最低价或无解 |
| 模拟服务有规定的故障码和traceId | 按实际响应分类错误；有服务trace时引用，无则明确使用客户端结果定位 |
| 固定简单商品和券规则 | 套餐与特调读取真实详情，优惠依当前报价校验 |

保留的机制：先判断状态、金额按状态填写、整单实时报价、区分硬性要求/偏好/替代许可、结论关联真实证据、输出前自检。新增六工具只读CLI用于接入和复现；它不是组合搜索器。

验证：提交版离线测试检查端点、工具允许清单、配置凭据不外泄和响应解析；真实只读烟测覆盖五次业务调用并取得报价。原研究成绩不转移到提交版，当前没有给提交版声称新的模型成功率。
